# School Website — Initial Layout

An early school website layout with a responsive navigation bar.

**Repository created:** 2021-04-04  
**Project status:** Learning project / historical snapshot  
**Earliest recorded commit (author date):** 2021-04-04

## Features and implementation

- Bootstrap navigation.
- Hover-pausable announcement marquee.
- Embedded map.

## Technologies

HTML, Bootstrap, jQuery.

## Project structure

| File | Purpose |
| --- | --- |
| [`index.html`](index.html) | Main page and user interface |

## Run or explore locally

```bash
git clone https://github.com/Avenger-Sonic123/School_Website1.git
cd School_Website1
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. The local server requires Python 3; browser-based dependencies may also require internet access.

Open the page to inspect the header and map.

## Current status and limitations

The HTML links to sections and a stylesheet that are not included.
